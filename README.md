# Zadanie 5: myCloud

Aplikacja PHP z osobnymi kontami zadania 5, folderami użytkowników oraz podglądem obrazów, filmów, dźwięku i PDF. Pliki TXT i inne typy mają jednakowe kafelki z ikoną.

## Uruchomienie

1. Wgraj zawartość `public_html` do katalogu strony.
2. Skopiuj `public_html/z4/db.example.php` jako `public_html/z4/db.php` i wpisz dane swojej bazy MySQL.
3. Skopiuj `public_html/z5/db.example.php` jako `public_html/z5/db.php`.
4. W bazie wykonaj `bazy-sql/z5.sql` i nadaj PHP prawo zapisu w `public_html/storage`.
5. Otwórz `/z5/`.

Wspólna fizyczna baza może przechowywać dane kilku zadań. Konta zadania 5 są oddzielone tabelą `z5_users`.
